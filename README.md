# Operating_Systems
Practical implementations of multithreading concepts, including parallel matrix multiplication and the Producer-Consumer problem with thread synchronization.

# Programs
1. Producer-Consumer Problem
An implementation of the classic Producer-Consumer problem using Python threads, a shared bounded buffer, and condition variables for synchronization.
Concepts: Thread Synchronization, Condition Variables, Shared Buffer, Producer-Consumer
  
2. Matrix Multiplication Using Threads
A 100 × 100 matrix multiplication program implemented using Python's ThreadPoolExecutor with 8 worker threads. The result is verified using NumPy, and an animation is generated to visualize the computation.
Concepts: Multithreading, ThreadPoolExecutor, Parallel Processing
